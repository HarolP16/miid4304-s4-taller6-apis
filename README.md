# MIID 4304 Taller 6 APIs

Repositorio del Taller 6 de MIID 4304 Despliegue de Soluciones Analiticas.

## Estructura inicial

- `app`: aplicacion FastAPI, esquemas, rutas y pruebas.
- `model-pkg`: paquete instalable del modelo analitico.
- `tox.ini`: automatizacion de pruebas y ejecucion de la API.
- `requirements.txt`: dependencias de ejecucion.

La primera etapa utiliza el paquete `model_abandono-0.0.1-py3-none-any.whl` suministrado con el taller.
